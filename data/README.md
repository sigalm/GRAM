# GRAM Data Inputs: Sources and Generation

This document describes the data files required by GRAM and how they were generated.

## Data Files by Directory

### `acs_data/` - Population Microdata

| File | Generated By | Source | Description |
|------|--------------|--------|-------------|
| `acs_age50_RACE-revised.RDS` | `generate_microdata.R` | IPUMS ACS | Full ACS extract for age 50, with derived variables |

**Variables derived in `generate_microdata.R`:**
- `RACEETH`: Collapsed race/ethnicity (0=NH White, 1=NH Black, 2=Hispanic, 3=Other)
  - Note the asymmetry with the parametric cohort path: `model/setup.R` defines only three
    levels (`v.RACEETH_val <- c(0,1,2)`, a three-element `p.RACEETH_start`, and a three-column
    `m.EDU_start`). A cohort built from this microdata carries all four categories through
    unchanged, because `f.initialize()` reads `RACEETH` and `EDUC` straight from the microdata
    and never consults `m.EDU_start`. A cohort generated parametrically instead draws only
    categories 0–2. Anything stratifying results by race/ethnicity should account for which
    path produced the cohort.
- `INCOME_CAT`: Income categories (0=<$9k, 1=$9-36k, 2=>$36k), based on [Angevaare et al. 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC8726570/)
- `MEDBUR`: Medical burden at baseline (0-10 conditions). This is the *starting* count only —
  during the simulation `f.update_MEDBUR()` accumulates further conditions up to
  `max(v.MEDBUR_val)`, which `model/setup.R` sets to 15. Derived using education-adjusted prevalence from [Chowdhury et al. 2023](https://bmcpublichealth.biomedcentral.com/articles/10.1186/s12889-023-15768-8):
  1. Baseline prevalence of 0-10 conditions from Figure 1 (averaged across sex)
  2. Education-adjusted odds ratios for 2+ conditions: College = 1.0 (ref), HS = 1.32, less than HS = 1.58
  3. For each individual: draw binary 2+ conditions using adjusted probability, then sample condition count from appropriate range (0-1 or 2-10)
- `APOE4`: Random assignment, 25% prevalence ([Di Battista et al. 2016](https://doi.org/10.1016/j.neurobiolaging.2016.03.003))

**Raw data source:** IPUMS USA, ACS 2022 1-year sample. Requires `usa_00004.xml` DDI file can be obtained by going to IPUMS data download page and submitting a data request. Variables requested: AGE, SEX, RACE, HISPAN, HCOVANY, EDUCD, FTOTINC, PERWT. (Note: the variable DIFFREM was also requested, but it was not used in the analysis.)

### `mortality/` - Life Tables

This directory holds two different things that are easy to confuse:

- the **model input** — the non-dementia death probabilities the simulation draws from, loaded
  into `l.inputs[["m.lifetable"]]` by `model/setup.R`;
- the **calibration benchmark** — an all-cause life table that calibration scores the model
  *against*, loaded by `calibration/benchmarking_helpers.R`.

They are different quantities (non-dementia vs all-cause) from different sources, and neither
is derived from the other.

| File | Role | Generated By | Source | Description |
|------|------|--------------|--------|-------------|
| `non_dementia_mortality_prob_bysex_byage.RDS` | Model input | `calculate_non_dementia_death_rates.Rmd` | CDC WONDER | Age- and sex-specific annual probability of non-dementia death |
| `table_prob_die_next_year.csv` | Calibration benchmark | *not recorded* | *not recorded* | All-cause annual probability of death (`age`, `qx`) from age 50. Read by `calibration/benchmarking_helpers.R`; the calibration protocol attributes it to SSA actuarial life tables. **No script in this repository generates it** — if it needs regenerating, its provenance has to be re-established first. |

**Methodology (model input):** CDC WONDER publishes population denominators only through age 84, so all-cause mortality rates can't be computed directly above that age, though death counts (for both all-cause and dementia-related deaths, ICD-10 codes F01.x, F03, F06.7, G30.x) are complete through age 100. All-cause rates are extrapolated to ages 85-100 via sex-specific log-linear regression on observed rates at ages 76-84; the dementia-attributable share of deaths needs no such extrapolation, since it's computed from counts (not rates) and is observed at every age. Non-dementia rate = all-cause rate x (1 - dementia share); this is algebraically equivalent to subtracting where both are directly observed. Three age/sex cells with dementia deaths suppressed (<10 by CDC WONDER, at ages 50-51) are treated as zero (<0.1% error). Rates are converted to annual probabilities via 1 - e^(-rate). Data from 2018-2024 (final 2018-2022, provisional 2023-2024). See `data/mortality/calculate_non_dementia_death_rates.Rmd` for the full derivation.

**Raw data files (from CDC WONDER):**
- `allcause_deaths_bysex_byage.csv`
- `dementia_deaths_bysex_byage.csv`

**Superseded files**, moved to `archive/`: earlier or by-age-only working versions that no live
code reads, and whose provenance is not recorded here: `allcause_mortality_clean.RDS`,
`mortality_rates_by_age.RDS`, `non_dementia_mortality_prob_by_age.RDS`,
`non_dementia_mortality_rates_by_age.RDS`, `lifetablebysex.xlsx`,
`GRAM Mortality Hazard Age Adjustments Worksheet.xlsx`, and the raw CDC WONDER exports
`allcause_mortality_by_age.txt`, `dementia_mortality_by_age.txt`,
`dementia_underlying_mortality_by_age.txt`.

### `cogcon/` - Cognitive Concern Probabilities

| File | Generated By | Source | Description |
|------|--------------|--------|-------------|
| `m.cogcon_reactive.RDS` | `generate_cogcon_probs.R` | KP preliminary data | Probability of reactive cognitive concern by age and true status |

- Selective: Healthy 5%, MCI 40%, Dementia 80%

## Regenerating Data Files

Each data file is regenerated by the script named in the "Generated By" column above. Run it
from the project root, so that the relative paths inside it resolve:

```r
setwd("<path-to-GRAM>")
source("data/acs_data/generate_microdata.R")
source("data/cogcon/generate_cogcon_probs.R")
source("data/mci_incidence/generate_mci_incidence_rate_by_age.R")
```

The mortality input is generated by a notebook rather than a script — knit or run
`data/mortality/calculate_non_dementia_death_rates.Rmd`, again with the project root as the
working directory.

**Note:** Some scripts require raw data files that are not included in the repository (e.g., IPUMS extracts). Contact the project maintainer for access, or submit a data request directly with IPUMS USA at <https://usa.ipums.org/usa/>. You can run the model without these data files (simply use the pre-generated microdata), but you will not be able to regenerate the microdata.
