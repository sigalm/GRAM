# GRAM Data Inputs: Sources and Generation

This document describes the data files required by GRAM and how they were generated.

## Data Files by Directory

### `acs_data/` - Population Microdata

| File | Generated By | Source | Description |
|------|--------------|--------|-------------|
| `acs_age50_RACE-revised.RDS` | `generate_microdata.R` | IPUMS ACS | Full ACS extract for age 50, with derived variables |

**Variables derived in `generate_microdata.R`:**
- `RACEETH`: Collapsed race/ethnicity (0=NH White, 1=NH Black, 2=Hispanic, 3=Other)
- `INCOME_CAT`: Income categories (0=<$9k, 1=$9-36k, 2=>$36k), based on [Angevaare et al. 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC8726570/)
- `MEDBUR`: Medical burden (0-10 conditions). Derived using education-adjusted prevalence from [Chowdhury et al. 2023](https://bmcpublichealth.biomedcentral.com/articles/10.1186/s12889-023-15768-8):
  1. Baseline prevalence of 0-10 conditions from Figure 1 (averaged across sex)
  2. Education-adjusted odds ratios for 2+ conditions: College = 1.0 (ref), HS = 1.32, less than HS = 1.58
  3. For each individual: draw binary 2+ conditions using adjusted probability, then sample condition count from appropriate range (0-1 or 2-10)
- `APOE4`: Random assignment, 25% prevalence ([Di Battista et al. 2016](https://doi.org/10.1016/j.neurobiolaging.2016.03.003))

**Raw data source:** IPUMS USA, ACS 2022 1-year sample. Requires `usa_00004.xml` DDI file can be obtained by going to IPUMS data download page and submitting a data request. Variables requested: AGE, SEX, RACE, HISPAN, HCOVANY, EDUCD, FTOTINC, PERWT. (Note: the variable DIFFREM was also requested, but it was not used in the analysis.)

### `mortality/` - Life Tables

| File | Generated By | Source | Description |
|------|--------------|--------|-------------|
| `non_dementia_mortality_prob_bysex_byage.RDS` | `calculate_non_dementia_death_rates.Rmd` | CDC WONDER | Age- and sex-specific annual probability of non-dementia death |
| `table_prob_die_next_year.csv` | `calculate_non_dementia_death_rates.Rmd` | CDC WONDER | CSV version for benchmarking |

**Methodology:** All-cause mortality rates minus dementia-related mortality rates (ICD-10 codes F01.x, F03, F06.7, G30.x), converted to annual probabilities. Data from 2018-2024 (final 2018-2022, provisional 2023-2024). Missing rates for ages 85+ were extrapolated using log-linear regression.

**Raw data files (from CDC WONDER):**
- `allcause_deaths_bysex_byage.csv`
- `dementia_deaths_bysex_byage.csv`

### `mci_incidence/` - MCI Incidence Rates

| File | Generated By | Source | Description |
|------|--------------|--------|-------------|
| `mci_incidence_rate_by_age.RDS` | `generate_mci_incidence_rate_by_age.R` | Gillis et al. 2019 | Age-specific MCI incidence per 1000 person-years |

**Methodology:** Log-linear interpolation of rates from [Gillis et al. 2019 Table 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC6416157). 

---

### `cogcon/` - Cognitive Concern Probabilities

| File | Generated By | Source | Description |
|------|--------------|--------|-------------|
| `m.cogcon_reactive.RDS` | `generate_cogcon_probs.R` | KP preliminary data | Probability of reactive cognitive concern by age and true status |
| `m.cogcon_selective.RDS` | `generate_cogcon_probs.R` | KP preliminary data | Probability of selective cognitive concern (e.g., annual wellness visit) |

**Values:**
- Reactive: Healthy 1%, MCI 10%, Dementia 30%
- Selective: Healthy 5%, MCI 40%, Dementia 80%

## Regenerating Data Files

To regenerate any data file, run its corresponding `generate_*.R` script from the project root:

```r
setwd("<path-to-GRAM>")
source("data/**/generate_*.R")
```

**Note:** Some scripts require raw data files that are not included in the repository (e.g., IPUMS extracts). Contact the project maintainer for access, or submit a data request directly with IPUMS via LINK HERE. You can run the model without these data files (simply use the pre-generated microdata), but you will not be able to regenerate the microdata.
